# Student Record System (Python First Year Project)

This is my basic Python project for the 1st year submission. It is a simple menu-driven program that takes student details, calculates their marks and total grades, and lets you search or save the data into a text file.

## Features
- Add student name, roll number, and 3 subject marks
- Automatically calculates total, average, and final grade
- View all saved student records at once
- Search for a student using their roll number
- Save all the entered records to a local `student_data.txt` file

## How to Run
1. Make sure you have Python installed on your PC.
2. Open your terminal or command prompt in this project folder.
3. Run the script using:
   ```bash
   python student_project.py
   ```
4. Choose an option from 1 to 5 in the menu to operate the program.
